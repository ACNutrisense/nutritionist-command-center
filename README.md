# Nutritionist Command Center

A lightweight internal launcher for Nutrisense Nutritionists.

## Behavior
- Health Portal, Circle, Fullscript, Playbook, The C.A.R.E. Framework, and Support Tickets open in the current sidebar view.
- Healthie opens in a new browser tab.

## Files
- `index.html` — page content and links
- `style.css` — layout and styling
- `images/hero.jpg` — header image
- `images/logo.png` — Nutrisense logo

## Updating a link
Open `index.html`, find the tool name, and replace the URL inside its `href="..."`.

## GitHub Pages
Publish from the `main` branch and `/(root)` folder under **Settings → Pages**.
